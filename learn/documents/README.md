# Documents & Compliance Hub Lessons

> Learn how standard tender templates, South African Standard Bidding Documents (SBD forms), and company returnables are managed and publicly distributed for SEO traffic.

---

## Overview

PMG Hub contains an integrated Document Management System backed by Cloudflare R2 object storage:

1. **Internal Admin Document Hub** (`apps/admin` -> `/documents`): Central storage for official SBD forms, company profiles, templates, and compliance guides.
2. **Public SEO Tender Forms Hub** (`apps/tes` -> `/sbd-forms`): Public-facing directory on TenderEdge Solutions allowing contractors and bidders across South Africa to search, preview, and download official SBD forms (SBD 1, SBD 4, SBD 6.1, SBD 8, SBD 9).
