# Playhouse Media Group (PMG) App Documentation (`apps/pmg`)

This folder contains documentation scoped specifically to the **Playhouse Media Group Public Marketing Application** (`apps/pmg`).

## Tech Stack & Architecture
- **Framework**: Astro 6 (SSR via `@astrojs/vercel`)
- **Language**: TypeScript + React 19 Components
- **Styling**: Tailwind CSS v4 + Vite
- **Analytics**: `@vercel/analytics`
- **Shared Packages**: `@pmg/db`, `@pmg/emails`, `@pmg/utils`
