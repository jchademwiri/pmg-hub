# Technical Event Services (TES) App Documentation (`apps/tes`)

This folder contains documentation scoped specifically to the **Technical Event Services (TES) Application** (`apps/tes`).

## Tech Stack & Architecture
- **Framework**: Astro 6 (SSR via `@astrojs/vercel`)
- **Language**: TypeScript + React 19 Components
- **Styling**: Tailwind CSS v4 + Vite
- **Analytics & Performance**: `@vercel/analytics`, `@vercel/speed-insights`
- **Shared Packages**: `@pmg/db`, `@pmg/emails`, `@pmg/utils`
